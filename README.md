This repository covers Arbitrum Timeboost's design and accompanying research specification. Arbitrum Timeboost is implemented as part of the [Arbitrum Nitro](https://github.com/OffchainLabs/nitro) node software stack. 

Note that the specification for Timeboost with a decentralized sequencer is available [here](https://github.com/OffchainLabs/decentralized-timeboost-spec).
